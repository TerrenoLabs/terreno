# Upgrading to 57.13.0

**Action required:** Yes
**Affected packages:** @terreno/ai, @terreno/ui

## Summary

Agent replies can use rich blocks (stepper, checklist, gallery, list, card eyebrow, copy), and hosts with `uiBlocks` on offer them in the prompt by default. `DataTable` number and date columns render differently, `neutral500` is a slightly darker gray, and the admin Roles screen groups permissions by resource. `@terreno/api` adds a per-route rate limiter, and `DocumentStorageApp` can be opened to signed-in non-admins. Action is required only for hosts with `uiBlocks` on that still have native builds from before this release.

## Breaking changes

### Rich blocks are offered in the chat prompt by default

**What changed**

With `uiBlocks` on, the chat system prompt now offers `checklist`, `gallery`, `list`, card `eyebrow`, and `copy`, plus `stepper` when a host action has `handles: "stepper"`. A native build shipped before 57.13.0 cannot render those blocks and shows an error banner for a reply that uses them.

**Why**

Rich blocks make agent replies more useful, so new hosts get them without extra setup.

**Migration**

Keep the old catalog until every shipped native build is on 57.13.0 or later:

```typescript
// Before
addGptRoutes(router, {aiService, uiBlocks: {hostActions}});

// After (until old native builds age out)
addGptRoutes(router, {aiService, uiBlocks: {hostActions, richBlocks: false}});
```

With `richBlocks: false` the prompt is the same as before. Validation accepts the new blocks either way.

### `DataTable` number and date cells

**What changed**

`columnType: "number"` columns right-align cells and header. `columnType: "date"` cells format an ISO string or `Date` as Luxon `DATE_MED` (date only, local zone). Strings that are not ISO dates show as before.

**Why**

Numbers line up by digit, and raw ISO timestamps were hard to read.

**Migration**

To keep the old look for a column, render it with `customColumnComponentMap`:

```typescript
// Before
{columnType: "date", title: "Created", width: 150}

// After (keep the raw value)
{columnType: "rawDate", title: "Created", width: 150}
// with customColumnComponentMap={{rawDate: ({cellData}) => <Text>{String(cellData.value)}</Text>}}
```

## Deprecations

None

## New capabilities

- `createRouteRateLimitMiddleware({name, max, windowMs, store?, keyBy?})` from `@terreno/api` for a fixed-window limit on one route.
- `DocumentStorageApp` `access: "authenticated"` (non-admins see only `users/<userId>/`) and `uploadRateLimit`.
- `scaleStepperHostAction`, `toggleChecklistHostAction`, `findAgentBlock`, and `runBufferedChatTurn` from `@terreno/ai`.
- `SegmentedControl` `size="sm"`; `Box` `accessibilityState` and `accessibilityLiveRegion`.
- The `neutral500` primitive is `#949494`. Override it with `setPrimitives({neutral500: "#9A9A9A"})` to keep the old gray.

## Verification

- `bun run compile` and `bun run lint` at the app root
- Send a chat prompt that asks for a checklist; on a current build it renders, and with `richBlocks: false` the agent replies with the old block types
- Open a screen with a `DataTable` date column and check the dates read as `Oct 10, 2026`
