# Upgrading to 58.3.0

**Action required:** Yes
**Affected packages:** @terreno/api, @terreno/test

## Summary

A minor release that removes the user-type casts from `@terreno/api` apps and lets a Better Auth app run with no Passport. Register your user type once with `TerrenoRegister` and callbacks see it. A new `legacyAuth` option turns the Passport and JWT routes off. `@terreno/test` becomes an optional peer of `@terreno/api`, so an app that imports `@terreno/api/testing` must install it. Five exports are deprecated and removed in 59.0.0 or later.

## Breaking changes

### `@terreno/test` is an optional peer dependency

**What changed**

`@terreno/api` no longer installs `@terreno/test`. It is an optional peer, and test files no longer ship in the `@terreno/api` tarball (a smaller install). Only an app that imports `@terreno/api/testing` without declaring `@terreno/test` is affected.

**Why**

Production installs should not download test tooling such as `mongodb-memory-server`.

**Migration**

```bash
# Before: @terreno/test arrived through @terreno/api
# After: declare it where you import @terreno/api/testing
bun add -d @terreno/test
```

## Deprecations

### `UserModel` type

`UserModel` is now an alias of `PassportUserModel`. It stays until 59.0.0, or three minors after deprecation, whichever is later.

```typescript
// Before
import type {UserModel} from "@terreno/api";
// After: Passport helpers need PassportUserModel; any other `userModel` option takes TerrenoUserModel
import type {PassportUserModel, TerrenoUserModel} from "@terreno/api";
```

### `createRouterWithAuth`

Removed in 59.0.0 (or three minors after deprecation, whichever is later). It authenticates with a `firebase-jwt` Passport strategy that `TerrenoApp` does not register.

```typescript
// Before
createRouterWithAuth("/things", addRoutes);
// After
createRouter("/things", addRoutes, [authenticateMiddleware()]);
```

### `setupEnvironment`

Same removal timing. `TerrenoApp` validates its own environment at startup.

```typescript
// Before
setupEnvironment();
// After
new TerrenoApp({userModel: User}).build();
```

### `gooseRestRouter` and `GooseRESTOptions`

Same removal timing. They are aliases of `modelRouter` and `ModelRouterOptions`.

```typescript
// Before
gooseRestRouter(Todo, options as GooseRESTOptions<TodoDocument>);
// After
modelRouter(Todo, options as ModelRouterOptions<TodoDocument>);
```

### Omitting `legacyAuth`

Legacy Passport/JWT auth stays on when `legacyAuth` is omitted, through 58.x and 59.x, and `TerrenoApp` logs one warning at boot. The default becomes `false` in 60.0.0. Set it explicitly now.

```typescript
// Before
new TerrenoApp({userModel: User});
// After: keep legacy auth
new TerrenoApp({userModel: User, legacyAuth: true});
// After: Better Auth only
new TerrenoApp({userModel: User, legacyAuth: false});
```

## New capabilities

- `TerrenoRegister` and `RegisteredUser`: register your user type once and `user` in modelRouter actions, `queryFilter`, permissions, and hooks is typed with no cast.

  ```typescript
  declare module "@terreno/api" {
    interface TerrenoRegister {
      user: UserDocument;
    }
  }
  ```

- `@terreno/api/expressUser`: opt-in typing for `req.user`. Add `import type {} from "@terreno/api/expressUser";` once.
- `TerrenoUserModel` and `PassportUserModel`: every `userModel` option takes a plain Mongoose model; only the legacy Passport helpers need `PassportUserModel`.
- `legacyAuth: false`: mounts no Passport and no legacy routes, reads no JWT secrets, and makes sockets and `POST /mcp` refuse legacy JWTs.
- `create-terreno-app` can scaffold a Better Auth-only backend with no Passport plugin and no JWT secrets.

## Verification

- `bun run compile` and `bun run lint` at the app root; after registering your user type, delete `as unknown as UserDocument` casts and compile again
- With `legacyAuth: false`: `curl -s -o /dev/null -w '%{http_code}' -X POST <api>/auth/login` returns `404`, and a protected route without a session returns `401`
- If you import `@terreno/api/testing`: `bun pm ls | grep @terreno/test` lists it
