### mentionUserIds?

> `optional` **mentionUserIds?**: `string`[]

Slack member IDs to @-mention. Incoming webhooks only notify when the
payload contains `<@U123…>` (or `<@W123…>`). Display names and emails in
the message text do not mention anyone.
