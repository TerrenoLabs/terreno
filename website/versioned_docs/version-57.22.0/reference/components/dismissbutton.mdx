## Props

| Prop | Type | Required | Description |
| --- | --- | --- | --- |
| `accessibilityHint` | `string` | Yes | The accessibility hint describes the results of performing an action on a control or view. It should be a very brief description of the result of interacting with the button. |
| `accessibilityLabel` | `string` | Yes | The accessibility label attribute identifies the user interface element. It should be a very brief description of the element, such as "Dismiss". |
| `onClick` | `reflection` | Yes | A function to call when the button is clicked, function should result in hiding the element rendering the dismiss button. |
| `color` | `keyof TextTheme` |  | Color of the icon on the dismiss button |
