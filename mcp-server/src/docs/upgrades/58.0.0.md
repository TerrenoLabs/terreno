# 58.0.0 (stub)

This file is a placeholder until Terreno 58 is cut. When that release ships, expand this page into a full upgrade note.

## `Filter` and `FilterProps` are removed

`@terreno/ui` removes the `Filter` and `FilterProps` aliases added as deprecations in 57.7.0. Import `DropdownPanel` and `DropdownPanelProps`. `FilterSelectMenu`, `FilterBoolean`, `FilterAccordion`, and `FilterChangesBadge` keep their names. See [57.7.0](57.7.0.md).

## HTTP rate limiting defaults on

`TerrenoApp` will enable HTTP rate limiting by default (memory store unless you pass `store`). Apps that must stay unlimited must pass an explicit off once 58 defines that API.

Until 58: omit `rateLimit` to leave the limiter off. See [Rate limiting](../../../docs/how-to/rate-limiting.md).

## Admin no longer takes an RTK `api`

`@terreno/admin-frontend` stopped injecting endpoints into your RTK Query API. Every admin request — model CRUD (including ObjectId and API-only models), `/admin/config`, scripts, roles, configuration, documents, comms, jobs, organizations, consent, announcements, and AI observability — now goes through one native `fetch` client that `AdminProvider` binds to your auth. The `api` prop, `useAdminApi`, `AdminApi`, `EndpointBuilder`, and admin `injectEndpoints` are removed. String-`_id` models with `adminBroadcast` keep the windowed syncdb path from 57.

Before:

```tsx
<AdminProvider api={terrenoApi} apiBase="/admin" apiOrigin={baseUrl} getAuthHeaders={getAdminAuthHeaders} routeBase="/admin">
  <AdminShellLayout api={terrenoApi} apiBase="/admin" routeBase="/admin">
    <Stack />
  </AdminShellLayout>
</AdminProvider>

<AdminScreenRouter api={terrenoApi} apiBase="/admin" name={model} routeBase="/admin" />
<AdminModelTable api={terrenoApi} baseUrl="/admin" modelName="User" />

const {useListQuery} = useAdminApi(terrenoApi, "/admin/users", "User");
const {config} = useAdminConfig(terrenoApi, "/admin");
```

After:

```tsx
<AdminProvider apiBase="/admin" apiOrigin={baseUrl} getAuthHeaders={getAdminAuthHeaders} routeBase="/admin">
  <AdminShellLayout apiBase="/admin" routeBase="/admin">
    <Stack />
  </AdminShellLayout>
</AdminProvider>

<AdminScreenRouter apiBase="/admin" name={model} routeBase="/admin" />
<AdminModelTable baseUrl="/admin" modelName="User" />

const {useListQuery} = useAdminModelApi("/admin/users", "User");
const {config} = useAdminConfig("/admin");
```

Same-origin cookie SPAs (like `@terreno/admin-spa`) pass `credentials="same-origin"` on `AdminProvider` and omit `apiOrigin` / `getAuthHeaders`. `getAdminAuthHeaders` is your host's `() => ({Authorization: "Bearer …"})` (example-frontend reads the Better Auth session token).

Product screens that reuse admin components outside the admin tree (for example `DocumentStorageBrowser` or `ConsentHistory` on a user tab) must render inside an `AdminProvider` with the same binding. Without one, admin hooks fall back to an unauthenticated same-origin `fetch` and warn once in development.

Checklist:

- [ ] Remove `api={…}` from every `@terreno/admin-frontend` component and from custom admin widget props.
- [ ] Drop the `api` first argument from `useAdminConfig`, `useAdminScripts`, `useAdminRoles`, `useConfigurationApi`, `useDocumentStorageApi`, `useConsentHistory`, `useOrganizationsApi`, `useCommsDashboardApi`, `useJobsDashboardApi`, and the `useAiObservability*Api` hooks. `useOrganizationsApi` also drops its unused `organizationId` argument.
- [ ] Query `refetch()` now returns a Promise; wrap fire-and-forget calls as `void refetch()`.
- [ ] Replace `useAdminApi(api, routePath, name)` with `useAdminModelApi(routePath, name)`. Hook names, `.unwrap()`, and response shapes are unchanged.
- [ ] Make sure one `AdminProvider` wraps the admin tree with `credentials` (cookie) or `apiOrigin` + `getAuthHeaders` (Bearer).
- [ ] Wrap any product-side reuse of admin components in `AdminProvider`.
- [ ] Delete type-erased casts such as `terrenoApi as unknown as AdminScreenProps["api"]` and any admin-only RTK tag types.
- [ ] Replace custom admin `injectEndpoints` with `useAdminRpc` + `useAdminRpcQuery` / `useAdminRpcMutation`.
