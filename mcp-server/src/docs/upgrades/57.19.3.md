# Upgrading to 57.19.3

**Action required:** Yes
**Affected packages:** @terreno/admin-frontend, @terreno/mcp, @terreno/rtk, @terreno/syncdb, @terreno/ui, create-terreno-app

## Summary

57.19.3 fixes modelRouter array-item PATCH when the item contains a nested document array, and
ships the changes merged after 57.19.2. Update the hosted MCP URL. Layouts that used a 768pt
cutoff now use the 1024pt desktop floor. `installTerrenoDevConsoleLogger` and `get_rtk_state`
still work, and both are deprecated.

## Breaking changes

None

## Deprecations

### `installTerrenoDevConsoleLogger` moves to `@terreno/syncdb`

**What changed**

Import `installTerrenoDevConsoleLogger({baseUrl})` from `@terreno/syncdb` (or
`@terreno/syncdb/devConsoleLogger`). The `@terreno/rtk` export remains a wrapper and still
accepts a call with no arguments.

**Why**

Browser log forwarding belongs with the local-first client, which already knows the API base URL.

**Migration**

```typescript
// Before
import {installTerrenoDevConsoleLogger} from "@terreno/rtk";
installTerrenoDevConsoleLogger();

// After
import {installTerrenoDevConsoleLogger} from "@terreno/syncdb";
installTerrenoDevConsoleLogger({baseUrl});
```

### `get_rtk_state` is an alias of `get_client_state`

**What changed**

`terreno-mcp-local` adds `get_client_state`. It reports `layer` as `rtk`, `syncdb`,
`syncdb+rtk`, or `none`. `get_rtk_state` stays registered for one release and returns the same
wrapped response. `terreno state` calls the new tool.

**Why**

Client state may live in SyncDB, RTK Query, or both.

**Migration**

Call `get_client_state` instead of `get_rtk_state`. Read `layer` before assuming an RTK Query cache.

## Behavior changes

### Hosted MCP URL

Point `.cursor/mcp.json`, `.mcp.json`, and `claude mcp add` at `https://mcp.terreno.app/mcp`.
`https://mcp.terreno.flourish.health/mcp` keeps serving for at least one more release. See
[Set up Terreno MCP](https://github.com/TerrenoLabs/terreno/blob/master/docs/how-to/set-up-terreno-mcp.md).

`create-terreno-app` starts the local server with `bunx -p @terreno/mcp terreno-mcp-local`. In an
existing app, add `"-p", "@terreno/mcp"` before `"terreno-mcp-local"` in the `terreno-local` args.

### Desktop floor is 1024pt

`Card`, `MarkdownEditor`, the admin shell, and the admin filter drawer use the narrow layout
below 1024pt. `isSupportedDesktopWidth` reports that floor. `ADMIN_FILTER_MOBILE_BREAKPOINT` is
1024.

### Admin nested object fields

`@terreno/admin-frontend` renders a nested object that has `items` in its admin config as a
titled group of controls instead of a JSON text box. `Mixed`, `Map`, and objects without `items`
stay on the JSON editor. Subfield test IDs use the dotted path (`admin-field-tasks.enabled`).

## New capabilities

Staff can record consent on a user's behalf with `POST /consent-responses/provisional`. See the
57.19.3 changelog for the RBAC action, status values, and the UI components.
