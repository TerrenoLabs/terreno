# Upgrading to 57.9.0

**Action required:** No
**Affected packages:** @terreno/ai, @terreno/ui

## Summary

This release adds durable and resumable GPT chat streams, safer attachment handling, operations-dashboard components, and improved web toast and file-picker behavior. Existing applications continue to work without migration.

## Breaking changes

None

## Deprecations

None

## New capabilities

- Configure `fileStorageService` to persist chat attachments and resume in-flight replies through `GET /gpt/histories/:id/stream`.
- Compose operations dashboards with scorecards, comparison series, spanning items, and richer chart presentation.
- Set `maxHeight` on growing `TextField` and `TextArea` components.

## Verification

- Run `bun run compile` and `bun run lint` at the app root.
- Exercise GPT chat attachment upload, reload during a response, and stream resumption when adopting the new AI capabilities.
- Check web toasts above an open modal and file selection through `FilePickerButton`.
