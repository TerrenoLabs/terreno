# Upgrading to 57.16.1

**Action required:** No
**Affected packages:** @terreno/ui

## Summary

This release keeps rapid typo corrections in web `TextField` and `TextArea` inputs, and adds a
reusable Terraform module for deploying Terreno backends to Cloud Run. Terreno's own infrastructure
also moves under `infra/flourish/` without changing deployed resource addresses.

## Breaking changes

None

## Deprecations

None

## New capabilities

### Reusable Cloud Run backend module

`terraform/modules/terreno-backend` provisions the Artifact Registry repository, runtime service
account, Secret Manager placeholders, and websocket-safe Cloud Run service for a Terreno backend.
Set `github_deploy` to add a keyless GitHub Actions deployer.

## Verification

- `bun run compile` and `bun run lint` at the app root
- On web, type a character into a `TextField`, immediately backspace it, and confirm it stays deleted
- Follow the Terraform example in `docs/how-to/deploy-backend-to-cloud-run.md` and run
  `terraform validate`
