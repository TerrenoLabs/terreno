# Upgrading to 57.10.0

**Action required:** Yes
**Affected packages:** @terreno/ai

## Summary

Signed file URLs from `GET /files/*gcsKey` now require the caller's session and only resolve that caller's uploads. This release also adds agent asks, block documents, a durable task harness, and local AI observability. An app that already sends the user's token when fetching that user's own files needs no change. An app that fetched a file URL without a session, or that fetched another user's key, must change.

## Breaking changes

### File download URLs require the owner session

**What changed**

`GET /files/*gcsKey` (`addFileRoutes`, and `AiApp` when `gcsBucket` is set) now requires authentication. An unauthenticated request returns 401. The route returns a signed URL only when the stored file's `userId` is the caller. Another user's file, including a request from an admin, returns 404, the same response as a missing key. Keys look like `uploads/<userId>/<ms>-<name>` and were previously guessable.

**Why**

Anyone who knew or guessed a key could obtain a signed URL for that object.

**Migration**

```typescript
// Before
const response = await fetch(`${apiBase}/files/${gcsKey}`);

// After
const response = await fetch(`${apiBase}/files/${gcsKey}`, {
  headers: {authorization: `Bearer ${accessToken}`},
});
// 401: send the session token.
// 404: the file is missing or belongs to someone else. Do not walk other keys.
```

`GET` and `DELETE /files/*gcsKey` also resolve the full key when it contains slashes. Express 5 passed the wildcard as path segments, so `uploads/<userId>/<ms>-<name>` used to 404.

## Deprecations

None

## New capabilities

- Turn on agent asks with `asks: true` (or `{kinds, approvals, maxFileSizeBytes}`) on `AiApp` or `addGptRoutes`. Asks stay off when the option is unset. See `docs/how-to/agent-ui-asks.md`.
- `@terreno/blocks` is the shared contract for asks and for block documents (headings, metrics, charts, tables, actions). `GPTChat` can render both.
- `@terreno/ai/harness` runs phased tasks that survive a process crash and can wait for a person. See `docs/how-to/build-a-durable-workflow.md`.
- `ObservabilityApp` adds local prompt versions, traces, evaluators, datasets, experiments, and a review queue, with admin screens in `@terreno/admin-frontend`. See `docs/how-to/observe-llm-calls.md`.

## Verification

- `GET /files/<own key>` with the owner's session returns a signed URL.
- The same request without a session returns 401.
- A key owned by someone else returns 404.
- `bun run compile` and `bun run lint` at the app root.
