# Upgrading to 58.0.3

**Action required:** No
**Affected packages:** None

## Summary

A patch release with bug and security fixes. `Avatar` no longer freezes release builds when its image fails to load. Mongo filters built from request values, nested-path helpers, and several regexes are hardened against untrusted input. Consumers only need to bump their `@terreno/*` versions.

## Breaking changes

None

The only `Changed` entry affects this repository's own test tooling (sharded `bun test` and Bun 1.4.4 on CircleCI). Nothing changes for consumer apps.

## Deprecations

None

## New capabilities

- **@terreno/syncdb:** `registerTerrenoDevClientDispatch`, `registerTerrenoDevStorage`, and `registerTerrenoDevCommand` for `terreno-mcp-local` dev tooling. These are optional.
- **@terreno/mcp-server:** `read_logs` sources `network` and `native`, client action dispatch, storage read/write, and dev commands.

## Verification

- `bun run compile` and `bun run lint` at the app root
- In a release build, show an `Avatar` whose `src` fails to load. It falls back to initials and the app stays responsive.
