# ChartCard

Card chrome for a chart or table: title, optional filter summary, and optional period badge action.

## Props

| Prop | Type | Required | Description |
| --- | --- | --- | --- |
| `children` | `ReactNode` | Yes |  |
| `title` | `string` | Yes | Card heading. |
| `filterSummary` | `string` |  | Optional context shown below the title row. |
| `onPeriodPress` | `reflection` |  | Makes the period badge pressable when provided. |
| `periodLabel` | `string` |  | Date range or relative period shown in the header. |
| `testID` | `string` |  | Root test id for the primary interactive element or container. |
