# Upgrading to 57.19.0

**Action required:** Yes
**Affected packages:** @terreno/cli, @terreno/mcp, create-terreno-app

## Summary

`@terreno/cli` and `@terreno/mcp` now require Bun 1.4.4 or newer. That release patches the
Brotli decoder (CVE-2026-111497). New apps from `create-terreno-app` use `oven/bun:1.4.4-slim`.
Existing images built from `oven/bun:1` or `oven/bun:1-slim`, and any backend produced with
`bun build --compile`, stay on the old decoder until they are rebuilt. This release also ships
`@terreno/test` helpers and testing skills, and fixes `create-terreno-app` when it is launched
through its package bin.

## Breaking changes

### `@terreno/cli` and `@terreno/mcp` require Bun 1.4.4

**What changed**

Both packages set `"bun": ">=1.4.4"`. Bun 1.4.0 through 1.4.3 are inside the affected range for
CVE-2026-111497, an out-of-bounds write in the Brotli decoder. `fetch`, `node:zlib` brotli APIs,
and `DecompressionStream` reach that decoder.

**Why**

A floating `oven/bun:1` tag can still resolve to an affected Bun. A compiled backend embeds the
Bun binary it was built with, so changing the tag in git does not patch a binary that is already
running.

**Migration**

```dockerfile
# Before
FROM oven/bun:1-slim

# After
FROM oven/bun:1.4.4-slim
```

Install Bun 1.4.4 or newer before upgrading `@terreno/cli` or `@terreno/mcp`. Rebuild any image
that uses `oven/bun:1` or `oven/bun:1-slim`, and rebuild any `bun build --compile` binary with
1.4.4. New `create-terreno-app` scaffolds already pin `oven/bun:1.4.4-slim`.

EAS build profiles in the Terreno repo stay on Bun 1.3.10 because that pin is part of the Expo
fingerprint. Those profiles remain on an affected Bun until a native rebuild is scheduled.

## Deprecations

None

## New capabilities

`@terreno/test` adds `waitUntil`, `waitForCalls`, `freezeTime`, `authWithToken`,
`expectAPIError`, `assertStrictResponseProperties`, opt-in service mocks, and
`@terreno/test/expo/*` helpers. `terreno-test-shard` and `terreno-test-hygiene` are new CLIs.
Testing skills (`terreno-test-setup`, `terreno-backend-tests`, `terreno-frontend-tests`,
`terreno-mobile-tests`) install with the other agent skills. `registerSimpleMongoPreload` waits
up to 60 seconds for a cold `mongod` start.

## Verification

- `bun --version` prints 1.4.4 or newer
- Rebuild the app image and confirm the runtime is Bun 1.4.4
- `bun run compile` and `bun run lint` at the app root
