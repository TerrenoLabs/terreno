# Upgrading to 57.21.0

**Action required:** Yes
**Affected packages:** @terreno/ui, @terreno/api, @terreno/admin-backend

## Summary

This release adds `theme.field` tokens for form inputs, MCP admin screens with an opt-in request log and tool switches, and an MCP OAuth consent screen in `@terreno/admin-spa`. The agent plugin `terreno-scan` is renamed `terreno-loop`. Two behaviors change: field colors no longer follow `surface`/`border` overrides, and deleting an `McpOAuthToken` revokes its whole connection.

## Breaking changes

### Form fields read `theme.field` instead of `surface.base` / `border.dark`

**What changed**

`TextField`, `SelectField`, `DateTimeField`, `HeightField`, and `OtpField` take their input background and border colors from the new `theme.field` tokens (`background`, `backgroundDisabled`, `border`, `borderFocus`, `borderError`, `borderDisabled`). Defaults equal the previous colors, so nothing changes unless you overrode `surface` or `border` to restyle inputs.

**Why**

Restyling inputs previously forced a change to every other `surface.base` and `border.dark` consumer.

**Migration**

```typescript
// Before
setTheme({surface: {base: "neutral050"}, border: {dark: "neutral400"}});

// After
setTheme({field: {background: "neutral050", border: "neutral400"}});
```

### `McpOAuthToken` delete revokes the whole connection

**What changed**

Document or query `deleteOne` on an `McpOAuthToken` row revokes that row's token family and keeps the rows, instead of removing one pair. `deleteMany` is unchanged.

**Why**

Removing one token of a pair left the connection usable through its sibling.

**Migration**

Nothing to change unless code relied on the row disappearing; query by `revokedAt` instead.

### Agent plugin `terreno-scan` is now `terreno-loop`

**What changed**

Skills are renamed `terreno-scan-*` to `terreno-loop-*`; `terreno-scan-loop` is now `terreno-loop-run`.

**Why**

The plugin covers resident loops, not only scans.

**Migration**

Claude Code installs migrate through the marketplace rename. In Cursor and Codex, uninstall `terreno-scan` and install `terreno-loop`. Campaign state at `.terreno/scan/<goal>.json` is unchanged.

## Deprecations

None

## New capabilities

- `mcpRequestLog` and `mcpToolSettings` on `TerrenoApp` (opt-in); `mcpAdminModels()` and `mcpAdminScripts()` in `@terreno/admin-backend`.
- MCP OAuth consent screen at `/console/oauth/consent` in `@terreno/admin-spa`.
- `theme.field` tokens in `@terreno/ui`.

## Verification

- `bun run compile` and `bun run lint` at the app root
- Visually check form inputs if you customized `surface` or `border`
